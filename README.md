# Job Search DB

## Описание
Job Search DB — это консольное приложение для поиска и анализа вакансий с помощью HeadHunter API,
с возможностью фильтрации, сортировки и сохранения результатов в JSON-файл.

## Структура проекта

~~~
job_search_db/
│
├── src/
│   ├── __init__.py
│   ├── api_hh.py              # Работа с HeadHunter API
│   ├── config.py              # Конфигурация (USER_AGENT, PATH_TO_JSON)
│   ├── company.py             # Класс для сохранения информации о компании
│   ├── db_manager.py          # Класс для выполнени запросов к базе данных
│   ├── utils.py               # вспомогательный функционал 
│   └── vacancy.py             # Класс Vacancy и работа с вакансиями
│
│
├── .flake8                    # Настройки flake8
├── .gitignore
├── main.py                    # Точка входа (запуск приложения)
├── poetry.lock
├── pyproject.toml
└── README.md                  # Этот файл

~~~

## Как использовать
Для установки и запуска проекта необходимо выполнить следующие шаги:

1.  **Клонируйте репозиторий:**

    ```
    git clone https://github.com/natali83911/job_search_db.git

    ```

2.  **Перейдите в папку проекта:**

    ```
    cd job_search_db
    ```

3.  **Установите зависимости с помощью Poetry:**

    ```
    poetry install
    poetry add --group lint flake8
    poetry add --group lint mypy
    poetry add --group lint black
    poetry add --group lint isort
    poetry add requests
    poetry add psycopg2-binary
       
    ```
4.  **Запустите приложение**
    ~~~
    python main.py
    ~~~
    
## Основные возможности
1. Поиск вакансий через HeadHunter API
2. Поиск вакансий по ключевому слову, региону и количеству на странице.
3. Получение списка вакансий с возможностью пагинации (перехода по страницам).
4. Получение списка работодателей по текстовому запросу.
5. Фильтрация и сортировка вакансий.
6. Фильтрация вакансий по ключевым словам в названии или описании.
7. Работа с базой данных.
8. Сохранение вакансий и информации о работодателях в базу данных PostgreSQL.
9. Установка и инициализация базы данных при первом запуске (если не существует).
10. Получение и удаление вакансий из базы данных.
11. Сохранение и экспорт данных.
12. Пользовательский интерфейс.



## Пример использования
~~~
Введите поисковый запрос (ключевое слово): IT
Введите ключевые слова для поиска вакансий: python
Выберите действие:
1 - Показать компании и количество вакансий
2 - Показать все вакансии
3 - Показать среднюю зарплату по вакансиям
4 - Показать вакансии с зарплатой выше средней
5 - Показать вакансии с ключевым словом 'водитель'
0 - Выход
~~~
